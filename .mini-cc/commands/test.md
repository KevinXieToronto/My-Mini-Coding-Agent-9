Run the project's test suite. $ARGUMENTS

If anything fails, read the failing test and the code it exercises, work out
the root cause, and fix it. Do not change the test to make it pass unless the
test itself is wrong — and if you think it is, say so before changing it.
Re-run the tests when you are done.
